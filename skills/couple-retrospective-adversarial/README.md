# 多轮对抗式对话

> 使用 delegate_task 驱动双代理模拟情侣冲突，最少8轮，输出五层心智定位与打分矩阵

---

## 效果展示

方A × 方B 对抗测试示例：

```
第7轮 | 方B：对方，我且问你，那件事究竟是个什么来历？
      方A：那是个来历不明的蠢物，你若嫌它碍眼，不如直说
      方B：你！我不过随口一问，你就这个态度？
      方A：我知你素来多心，可我这心里，也不想多解释
      方B：...

情绪走向：↑ 升温（试探 → 质疑 → 冷淡）
回应质量：中（方A 没有接住情绪）
雷点：方A 说"蠢物"，触发方B 安全感
话题层级：事实层 → 情绪层（未对齐）
```

## 快速开始

### 准备素材

任何冲突场景均可：真实情侣 / 文学IP / 用户描述

```python
# 素材示例
scenario = """
方A × 方B，某年某月某日晚

背景：
- 方A 和 方B 是情侣/曾经是情侣
- 方A 主动邀请方B 晚上出去玩
- 方B 一直很冷淡，说"不用了""没意思"
- 方A 连续追问，方B 最后说"别客气"
- 这是他们分手前的最后一次邀约
"""
```

### 执行对抗

调用 `delegate_task`，每批2个子任务（同时运行）：

```python
# 格式：用 goal 而非 batch（batch 有 bug）
tasks = [
    {"goal": "你是方A。第1轮台词...", "context": scenario, "toolsets": [...]},
    {"goal": "你是方B。第1轮台词...", "context": scenario, "toolsets": [...]}
]
```

### 追踪轮次

每轮需要把上一轮两个代理的台词都放进下一轮的 context：

```
第N-1轮：
🎙️ 方A："..."
🎙️ 方B："..."

第N轮（最终陈述）...
```

## 流程详解

### Step 0：确认素材

用户提供故事片段或角色设定。可以是：
- 真实情侣聊天记录
- 文学IP（如 A × B）
- 直接描述冲突

### Step 1：建立对抗结构

每轮对抗由两个代理**同时生成各一段台词**：
- Agent A：生成自己的台词
- Agent B：生成自己的台词
- 两段合在一起为一轮完整对话

**不要让一个代理生成两个人的台词**——那样失去了对抗性。

### Step 2：分批驱动子代理

**关键**：用 `goal` 格式，不要用 `batch` 格式（batch 有 bug）

```python
tasks = [
    {"goal": "你是方A。第N轮台词...", "context": "背景", "toolsets": [...]},
    {"goal": "你是方B。第N轮台词...", "context": "背景", "toolsets": [...]}
]
```

### Step 3：追踪轮次

最少 **8 轮**：
- 前 6 轮：基础冲突展开
- 第 7-9 轮：深入/反转
- 第 10 轮+：收束/最终陈述

### Step 4：输出分析报告

五层心智框架 + 打分矩阵

## 五层心智定位

```
Layer 0（身份）：
  方A：...
  方B：...

Layer 1（表达DNA）：
  方A：关键台词模式
  方B：关键台词模式

Layer 2（心智模型）：
  方A：爱 = ...
  方B：爱 = ...

Layer 3（决策启发式）：
  方A：被质疑 → ...
  方B：被冷落 → ...

Layer 4（反模式）：
  方A：...
  方B：...

Layer 5（诚实边界）：
  方A触碰了：...
  方B触碰了：...
```

## 打分矩阵

```
方A总分：X/10
  情绪控制：X/10
  沟通质量：X/10
  踩雷清单：X/10
  修复态度：X/10
  关系增益：X/10

方B总分：X/10
  （同上五项）

双方均 ≥ 6分 → 通过
```

## 行动承诺

每方 2 条具体承诺：

```
方A 承诺：
1. 下次冲突时，先接住对方情绪再讲道理
2. ...

方B 承诺：
1. 需要空间时，直接说"我需要独处"
2. ...
```

## 踩坑记录

1. **delegate_task batch 格式 bug**
   - batch 格式有时只跑一个任务
   - 解决：改用 goal 格式单任务

2. **角色超时问题**
   - 方A 生成台词较快，方B 较慢（约30秒）
   - 解决：分开设置 timeout

3. **12轮刚好踩线**
   - 要超过6分钟建议跑14-16轮
